Ember Court — an original lane-battle card game. Play creatures into three lanes, spend growing mana, and outwit the Warden. Ember beats Gale, Gale beats Stone, Stone beats Tide, Tide beats Ember, and a winning element strikes +1 harder. Twenty life, twenty-four cards, one court.

## Run it

```sh
node serve.ts
```
